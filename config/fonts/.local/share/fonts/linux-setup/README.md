# Fonts for the themes

Free fonts the themes use that aren't packaged on Arch or Fedora, from github.com/google/fonts (SIL Open
Font License 1.1, which allows bundling; each licence sits next to its font). Stow links them to
~/.local/share/fonts/linux-setup/; `fc-cache` picks them up.

| Font | Theme |
|---|---|
| Martian Mono | Console |
| Outfit | Pebble, Garden, Halo |
| Archivo, Archivo Black | Poster, Atlas |
| Fraunces | Noir |
| IBM Plex Sans | Workstation, Glass, Noir, Zen, Mist |

Packaged fonts (packages/): JetBrains Mono Nerd
(Monolith, icons everywhere), Cantarell (Canvas), Inter.
