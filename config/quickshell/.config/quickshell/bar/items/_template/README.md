# Bar item: NAME

One or two lines: what it shows, when it hides, what a click does.

Its own settings (put their defaults in `defaults.json` under `settings`): none.
Shared settings: [docs/bar.md](../../../../../../../docs/bar.md).

To make an item: copy this folder to `bar/items/<id>/` (lower-case, no leading underscore), edit the three
files (`category` in defaults.json: Desktop, System, Connections & sound, Time & info or Other picks its group
in Settings → Menu Bar), then add `<id>` to a bar section there.
