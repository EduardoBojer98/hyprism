# Bar item: weather

The sky now and the temperature. Click opens the forecast beside it. Hidden until the first forecast arrives (or shows a bare icon while no place is saved). The last forecast is kept in ~/.cache/hyprism/weather.json.
The places and units are in Settings → Weather.

Its own settings: none. Shared settings (icon, format, click, rightClick, scroll, tooltip, warn, critical, enabled):
[docs/bar.md](../../../../../../../docs/bar.md). `warn` and `critical` compare against the temperature.
