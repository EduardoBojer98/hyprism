# Bar item: battery

The battery level and whether it charges. Hidden on a machine without a battery. Turns red when low (its own
rule, so no `warn` / `critical`). Click opens Settings → Power. Where the percentage shows is set in Settings → Menu Bar.

Its own settings: none. Shared settings (click, rightClick, scroll, tooltip, enabled): [docs/bar.md](../../../../../../../docs/bar.md).
