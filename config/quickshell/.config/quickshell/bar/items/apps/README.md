# Bar item: apps

The dock inside the bar: pinned apps, then the other running ones, with a mark under each open app and the accent
under the focused one. Click brings an app up (again: its next window) or starts it; middle-click opens a new window.
Settings → Dock decides what is pinned, combined and labelled.

Its own settings: none. Shared settings (enabled): [docs/bar.md](../../../../../../../docs/bar.md).
