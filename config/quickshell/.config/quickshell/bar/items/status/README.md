# Bar item: status

Network, Bluetooth, sound and battery together in one item. Click opens the flyout of the icon you click (network,
Bluetooth, volume or battery); from the keyboard it opens the Control Center. Scroll changes the
volume (defaults.json: scroll).

Its own settings: none. Shared settings (icon, format, click, rightClick, scroll, tooltip, enabled): [docs/bar.md](../../../../../../../docs/bar.md).
