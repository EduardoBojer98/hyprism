## Top 5

1. Docker on first use (#1): ~5 s faster boot, 10 minutes.
2. CI with the container test (#2): a reinstall never surprises you.
3. `install.sh update` (#3): one command or button for all updates, with snapshots already behind it.
4. Mask `nvidia-powerd` (#4): cooler and longer on battery after AC plug-in.
5. Snapshots documented and checked, plus a `/home` plan (#5): rollback you know how to use.
