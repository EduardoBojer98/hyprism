Neon desktop palettes

Three directions for the Hyprland + Quickshell desktop, each drawn on the same near-black base. Each mock shows the bar, a focused terminal window with its glowing gradient border, an unfocused window, the launcher, a notification and the lock screen. Body text stays light grey on near-black, and neon only marks state. Pick one as the default. The other two stay as switchable themes.

Main accent: focused workspace, active border start, selection, launcher field, lock clock.
Second accent: active border end, keywords, lock glow. Never used for body text.
Status colours: success, warning and error, picked so they never read as an accent.
