Twelve rices, twelve desktops

Each one changes where things are, not only what colour they are: the bar's edge and shape, whether there's a dock, how the launcher works, the typefaces, the corners, the window frames and the motion. Every rice also gets its own lock screen, terminal palette and a wallpaper drawn for it. Pick any, switch between them with one command.

Monolith

The desktop as a terminal. No dock, no glass, no curves: a text bar at the bottom, a command line across the top, windows packed edge to edge with hard 2px frames.
